# Session 16 Review — live investigation-console TUI (2026-08-02)

## Executive Summary

Upgraded the TUI from a static report viewer into a **live investigation
console**: a status bar (AUTH/MODE badges + live counters), a streaming
activity feed, and keyboard controls that issue engine commands — the
ADR-9 computed next-steps, the NetAudit admin-port probe, save, and
export — with three liveness modes (on-demand, auto-run, continuous
monitor) per the user's ask_user choice, plus auto-save at launch. The
engine is untouched; the TUI remains a pure control layer (ADR-7),
invoking engine functions only. 231 tests pass (was 220), ruff + mypy
clean. Live-verified in a pty (expect), and code review caught 3 real
bugs, all fixed with regression tests.

## Discovery Phase

- Read the full TUI surface (app.py, widgets.py, theme.py), the
  Investigation aggregate, the steps registry, the audit module, and
  test_tui.py constraints before designing.
- Verified Textual 8.2.8 APIs on disk before writing: `App.bind`
  exists but `App.unbind` does not; `RichLog.write` (not
  `Log.write_line`); parameterized actions (`run_step(0)`) work in
  `BINDINGS`; `@work(thread=True, exclusive=True)`.

## Baseline Health

- Live pty run (expect, TERM=xterm-256color): console rendered, `1`

## Findings

| Severity | Finding | Status |
|---|---|---|
| Critical | Worker exceptions other than `AcquisitionDenied` (e.g. a failing engine action) killed the worker thread without clearing `_busy` — the console would refuse every later action with "busy" forever | Fixed (6056dfc) |
| High | Monitor mode re-appended the same `SERVICE_REACHABLE` records every tick — evidence list, audit log, and `run_checks` input grew unboundedly | Fixed (6056dfc) |
| High | Step and probe workers had separate `exclusive` queues, so both could run concurrently and whichever finished first cleared `_busy` mid-flight | Fixed (6056dfc) — single shared exclusive worker |
| Low | `_update_open_ports` compared `ev.type.value` string instead of the enum; full re-render on every monitor tick even with no change | Fixed (6056dfc) |

Auth gating (ADR-15: single `--authorized` unlocks active actions,
passive refuses with a feed hint) and ADR-7 compliance (engine commands
only) were verified clean. No dead code or unused imports.
